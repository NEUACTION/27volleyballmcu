# 发球光电以后改接 UART7（7口）

## 接线变化

**原发球USART3的PD8 TX / PD9 RX，迁至本合并主控的UART7：PE8 TX / PE7 RX。**

|主控引脚|连接光电模块|
|---|---|
|PE8（UART7 TX）|模块RX|
|PE7（UART7 RX）|模块TX|
|GND|模块GND，共地|

通信为 **115200、8数据位、无校验、1停止位（8N1）**。主控沿用接球工程已存在的UART7初始化；未新增USART3配置。以上为MCU管脚名，PCB接插件脚号须按板上丝印/原理图对应；不能只凭“7口”猜插头方向。

## 只保留发球用的 ps_num[3]

UART7查询帧使用原发球协议，共9字节：

```text
字符：I  O  0  0  0  0  0  CR LF
十六：49 4F 30 30 30 30 30 0D 0A
```

接收必须完整符合 `IO`＋五个ASCII `0/1`＋`CRLF`。五个数字中的第4项（整帧下标5）转换成数值0/1，**只更新 `ps_num[3]`**；其他15项保留。没有照搬ADC读取、阀门发送等副作用。

示例 `IO10101\r\n` 对应五项1、0、1、0、1，因此PS3=0；`IO10111\r\n` 则PS3=1。不能发送字面反斜杠r/n，实际帧尾必须是0D 0A。

上电PS3初值1，避免尚未收到传感器时默认零触发；本地诊断 `ps3_valid=0`。收到首个合法完整帧后置1（不增加PC字段）。小电脑通过USB反馈byte13接收原数值，组合发球按原逻辑连续0累计1000个5ms周期触发，不翻转电平。

`SendPs()`仅在UART7发9字节查询，中断发送HAL忙则丢本次查询，不叠加重试。正常接收/错误恢复都按1字节续收，遇非法字节或新I会丢弃/重新定位候选帧。合法值会保持到下一合法帧，当前无传感器失联时效检测。

## 原代码保留范围

原20字节缓存、UART10链路和其余光电源码保留；旧UART7队列解析不得覆盖PS3。**UART7现在只接原发球9字节设备，不能继续在同一口接20字节设备，也不能将两个独立模块TX直接并接。**

## 接机验证

1. 确认迁至PE8/PE7、TX/RX交叉、共地，串口参数115200 8N1。
2. 无有效响应时检查PS3=1、ps3_valid=0，不触发发球计数。
3. 发合法9字节帧，分别将第四数字置0/1；确认主控PS3、小电脑byte13/ROS `ps_num3` 同步，其他15项不变。
4. 用截断、非法数字、连续帧测试；只允许完整合法帧更新。
5. 在禁止电机动作时观察组合计数，确认原0电平累计触发条件，再按机构调试流程验证动作。

当前已完成源码接入和ARM编译/链接验证，未做实物串口或动作验证。
